# Клавіші

Безкоштовний статичний тренажер сліпого набору українською мовою. Працює без сервера, реєстрації та зовнішніх залежностей.

## Можливості

- 24 послідовні уроки української розкладки;
- підказки пальців на екранній клавіатурі;
- швидкість, точність і час у реальному часі;
- адаптивна практика слабких клавіш;
- історія занять і серія днів;
- збереження прогресу в `localStorage` браузера;
- адаптивний інтерфейс для різних розмірів екрана.

## Локальний запуск

Відкрийте `index.html` у браузері або запустіть локальний сервер:

```powershell
python -m http.server 8000
```

Після цього відкрийте `http://localhost:8000`.

## GitHub Pages

1. Створіть публічний репозиторій на GitHub і завантажте файли.
2. Відкрийте **Settings → Pages**.
3. У **Build and deployment** виберіть **Deploy from a branch**.
4. Виберіть поточну гілку (`master`), каталог `/ (root)` і натисніть **Save**.

Сайт буде доступний за адресою `https://<користувач>.github.io/<репозиторій>/`.

## Приватність

Застосунок не передає введений текст або статистику назовні. Усі результати зберігаються локально у браузері користувача.
