# План і рішення

- Формат: статичний HTML/CSS/JavaScript без залежностей — найпростіший безкоштовний деплой на GitHub Pages і повна приватність локального прогресу.
- Методика: точність перед швидкістю, поступове відкриття клавіш, короткі регулярні сесії, підказки пальців та адаптивне повторення помилок.
- Дані: статистика зберігається в `localStorage`; сервер і реєстрація не потрібні.
- Розвиток курсу: 100 оригінальних українських уроків із чотирикроковим циклом «рухи → слова → речення → контроль», натхненним загальними принципами послідовного навчання «СОЛО на клавіатурі», без копіювання авторських вправ.
- Закріплення моторної пам'яті: довгі повторювані серії, облік усіх помилкових натискань навіть після Backspace та пороги точності 97% / 95% / 90% у міру просування курсом.
